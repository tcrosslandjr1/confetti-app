# Confetti Cultural Activity Universe
## Complete Activity System + 3-Tier Plans + DMV Venue Database

> **Purpose:** The master activity library the Recommendation Agent uses to build culture-first day and night itineraries. Organized into 9 activity categories with individual activities the agent can mix and match. Each assembled plan has 3 budget tiers (Cheap / Mid / High-End) and real DMV venue anchors.

> **How It Works:** The agent picks activities from one or more categories, assembles them into a Boarding Pass itinerary (Warm-up → Main Event → Twist → Finale), and maps to real venues. Categories are designed to combine — a "Yacht Day + Southern Night" pulls from Categories 1, 3A, and 6.

# PART 2: 3-TIER ASSEMBLED PLANS

> These are pre-built itinerary templates the agent uses as starting points. The agent can also freestyle-assemble plans by pulling activities from any category above.

## Plan 1: Southern Day + Night

### Tier 1 — Cheap ($20-$40)
**Flow:** BBQ plates from a smokehouse → Thrift store run or park hangout → Blues bar or live music spot
**Twist:** TikTok picnic at the waterfront, sauce-tasting challenge

### Tier 2 — Mid ($50-$90)
**Flow:** Soul food dinner (Oohh's & Aahh's, Florida Avenue Grill) → Line dancing or live band bar → Whiskey bar nightcap
**Twist:** Spades tournament at the bar, dessert detour for banana pudding

### Tier 3 — High-End ($120-$250)
**Flow:** Upscale Southern dinner (Georgia Brown's, MARCUS DC) → Bourbon tasting at a private lounge → VIP jazz lounge (Blues Alley)
**Twist:** Private chef add-on, blind bourbon tasting competition
