# Girls Night plan template

Default 4-stop flow. Source of truth: `src/lib/agents/girls-night-template.ts`.

1. **Shareable dinner** (food) — seafood/crab, tapas, KBBQ, Caribbean, Latin, or soul food. Optimized for group plates + photo-friendly presentation.
2. **Fit check + photos** (moment) — non-venue stop; surfaced as a mural/landmark/rooftop pin near the dinner spot.
3. **Lounge, hookah, karaoke, or dancing** (social) — picks one based on `vibe`: chill → lounge/hookah, playful → karaoke, turn-up → dance club.
4. **Dessert or late-night bites** (late-night) — within 1mi of the social stop, open past midnight.

## Rules
- Used as the default when `occasion = girls-night` and no template override.
- Stop 2 is always inserted; never counted toward boosted-venue quota.
- Stop 3 swap-eligible via group vote (see scenario-maya-dc).
- Cultural anchors bias stop 1 only.
