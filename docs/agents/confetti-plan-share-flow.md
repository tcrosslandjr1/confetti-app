# Confetti — Plan Share Flow

What happens AFTER a plan is generated. Plugs into the universal flow's
Step 5 (Save / Customize / Invite / Post).

```text
Generated plan
  |
  +--> Share privately
  |     Send to friends, partner, group chat
  |
  +--> Post publicly
  |     Other users can like, remix, save, or ask to join
  |
  +--> Create invite
  |     Date, time, city, budget, dress code, RSVP
  |
  +--> Export
        Instagram story, TikTok caption, text message, calendar link
```

## Agent rules

- Always offer all four actions on any generated plan surface.
- Public posts default to remixable (others can fork the plan).
- Invites must capture: date, time, city, budget, dress code, RSVP list.
- Export formats: IG story image, TikTok caption text, SMS-friendly summary,
  .ics calendar link.
- Reel share = 10 Confetti pts; invite = 50 pts; save plan = 5 pts (see Core memory).
