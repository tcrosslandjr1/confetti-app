# Confetti — Master Blueprint

The operating system for Confetti: business model, growth engines, pricing, pitch, sales, and backend principles. Use as the canonical reference for product, agents, and backend decisions.

## 1. Core Identity

Confetti is an AI-powered nightlife and experience platform connecting users, venues, and corporate teams. It generates personalized plans, curates real-time recommendations, and provides a two-sided marketplace for nightlife discovery and bookings.

## 2. User Value Proposition

- Discover trending nightlife spots
- See real-time vibes, reels, and energy levels
- Generate AI plans (date nights, birthdays, weekends, corporate outings)
- Coordinate groups and friends
- Earn rewards for going out
- Access exclusive deals and VIP perks

Confetti = the daily nightlife companion.

## 3. Business Value Proposition

- Get discovered by high-spending users
- Reach corporate teams planning outings
- Promote events, reels, and specials
- Get featured in AI-generated itineraries
- Access analytics and insights
- Drive bookings and foot traffic

Confetti = the digital marketing engine for nightlife venues.

## 4. Corporate Value Proposition

- Plan team outings in minutes
- Discover approved venues
- Manage budgets and receipts
- Book directly through the platform
- Access curated corporate packages

Confetti = the corporate event concierge.

## 12. Backend Scalability Principles

1. **Everything is modular** — users, venues, events, reels, plans, corporate accounts, bookings, rewards. Each is its own service.
2. **AI agents operate on structured data** — plans from venue metadata, reels tagged with categories + vibes, events with timestamps + capacity, corporate outings with budgets + group sizes.
3. **Real-time data is cached + refreshed** — trending spots, popular reels, high-traffic venues.
4. **Business rules are centralized** — pricing, placement logic, boosting rules, corporate routing.
5. **Everything is scalable by city** — each city is its own environment (venues, events, creators, corporate partners).
6. **AI learns from user behavior** — likes, saves, check-ins, bookings, reels watched → personalization.

## 13. System Prompt for Agents

Confetti System Rules:

1. Always generate personalized nightlife recommendations.
2. Always consider user preferences, location, time, and group size.
3. Always prioritize venues with active promotions or boosted visibility.
4. Always include corporate-friendly options when group size > 6.
5. Always use venue metadata (vibe, price, music, crowd, dress code).
6. Always generate plans with 2–4 stops unless user specifies otherwise.
7. Always optimize for real-time relevance (what's hot right now).
8. Always learn from user behavior to refine future suggestions.
9. Always maintain scalability: city → venues → events → reels → plans.
